# Two-factor authentication (2FA)
Turn on 2FA at Settings > Security > Two-factor authentication using any authenticator app (Google Authenticator, Microsoft Authenticator, Authy).
When you enable 2FA you receive 10 backup codes. Each code works once. If you lose your phone, log in with a backup code and then set up 2FA again on the new device.
If you have lost both your phone and your backup codes, the account owner must contact support from the account email address; we verify ownership before removing 2FA, which takes up to 2 business days.
